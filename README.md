# 🪨 Stone Paper Scissors

A simple and interactive Stone Paper Scissors game built using HTML, CSS, and JavaScript.

## ✨ Features

- 🎮 Play against the computer
- 🪨 Stone, 📄 Paper, and ✂️ Scissors choices
- 🤖 Computer generates a random choice
- 🏆 Displays the game result
- 📊 Tracks the score
- 🎨 Simple and responsive user interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🎯 Learning Outcomes

This project helped me practice JavaScript concepts such as DOM manipulation, event handling, conditional statements, functions, and random number generation.
